# Contributing

Issues and pull requests are welcome, especially from people who build cabinets.

- **Bug or wrong part size?** Open an issue with the job JSON you used and what you expected.
- **New cabinet type or rule?** Describe how your shop builds it. Keep defaults generic; shop-specific standards belong in the full [millwork-mcp](https://github.com/Toolibi/millwork-mcp).
- **Code:** `pip install -r requirements.txt`, then `python -m pytest -q` must pass. Add a test for any new behaviour.
- **Tool descriptions** are read by AI models: say what the tool does, when to use it, its parameters, what it returns and give an example.

By contributing you agree your work is released under the MIT license.
